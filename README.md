# Portfólio de Thassila Lorena

Projeto de currículo/portfólio para estudante de Informática para Internet, feito com HTML, CSS e JavaScript.

## Arquivos
- `index.html` — conteúdo da página.
- `style.css` — cores, layout e responsividade.
- `script.js` — menu para celular e ano automático no rodapé.

## Como executar no VS Code
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio_raquel` no Visual Studio Code.
3. Instale a extensão **Live Server**, se ainda não tiver.
4. Clique com o botão direito em `index.html`.
5. Escolha **Open with Live Server**.

## Personalização
Edite o `index.html` para trocar o e-mail, telefone, cidade, escola e textos pelos seus dados. Você também pode adicionar novos projetos e habilidades.
